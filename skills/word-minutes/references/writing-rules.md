# 議事録 表現ルール・思想

## 議事録の本質

議事録は速記録ではない。話したことを忠実に書く必要はなく、ポイントを整理した上で書く。
議事録作成者は「書記」ではなく、会議内容を理解し構造化する専門家である。

### 議事録の4つの目的

1. **関係者への念押し**: MTG終了時に確認したアクションプランを担当者にリマインドし、確実に実行に移してもらう
2. **証拠残し**: 決定事項に対して後日異論が出た場合、合意に至った過程を示して異論を抑えることができる
3. **根回し・様子伺い**: 議事録送付とあわせて懸案事項を自然に相談。依頼作業の進捗を"ついでに"確認できる
4. **メンバー育成**: 理解度を確認し認識の齟齬があれば正確な知識を教えられる

### 議事録の読み手

| 構成要素 | 意識すべき読み手 | ポイント |
|----------|-----------------|----------|
| 決定事項 | 会議参加者 / 関係者 | 認識を合わせたいポイントを簡潔・明解に記述 |
| ToDo | 会議参加者 | Dueと担当と共に記載 |
| 議事詳細 | 会議参加者 / 関係者 | 会議に参加しない人でもポイント・流れがわかるように |

## 決定事項とToDoの定義

### 決定事項とは
- 会議の結論として**新たに決定した事項**
- 非業務の内容（懇親会等）は決定事項に挙げない
- クライアントが成果物を確認するのは当然のことであり、敢えて決定事項に書く必要はない

### ToDoとは
- 会議中に挙げられた「しなければならないこと」＋**担当者**＋**Due（対応期限）**
- **会議前から元々やると決めていた事項はToDoにならない**（ただし念押ししたい場合は除く）
- 担当者・期限が不明確な場合は、妥当な日付を入れた上でSVに相談

### 決定事項/ToDoの書き方
- 「～する。」または体言止めで統一
- 内容を読んだだけで意味の通じる文章にする
  - NG: 「データを送付する。」
  - OK: 「期限切れの在庫データを関連部門に送付する。」
- 主語・目的語を省略しない。特にToDoでは「誰が」「何を」を明確に

## 議事詳細の構造化ルール

### 構造化の原則
- **時系列ではなく議題に沿って整理**（話した順ではなく意味のある分類で）
- 各議題・論点に対して**結論・課題・今後のアクション**を明記
- トピック名に「xxxについて」を付けるのはNG

### 構造化の4ステップ

1. **箇条書き**: まず文章を箇条書きで記載
2. **接続詞によるつなぎ**: 順接「それで」、逆接「しかしながら」、添加「さらに」、転換「一方で」等
3. **適切な見出し**: アジェンダごとにタイトルを付与
4. **結論を端的に記載**: 決定事項と今後のアクションは一瞥で分かるように

### 議事内容の理解
- 会議で話された内容をきちんと理解した上で記載する
- 自らの理解が曖昧な場合は、SVもしくは知見のあるメンバーに確認してから記載
- PJメンバーの共通語を「わかった気」で記載しない。正しく理解してから記載する
- 明らかな言い間違いは訂正して記述する（速記係ではない）

### 議事詳細の編集ルール
- **質問に対する返答を必ず明記する**（質問だけ書いて回答なしはNG）
- **不適切な発言は表現を変更して記述する**（文書として残るため）
- **重複・前後矛盾する発言は編集**して意味が通るように整理する
- **省略された主語を補足**し、意味のつながる文章にする

### セルフレビューの8観点
文章化後に以下の観点でセルフチェックを行う:
1. **誰が？** — 主語が明確か
2. **いつ？** — 時期・期限が具体的か
3. **どういう？** — 内容が具体的に書かれているか
4. **何の目的で？** — 目的・背景が読み取れるか
5. **いつから？** — 開始時期が明確か
6. **なぜ？どのように？** — 理由・方法が書かれているか
7. **誰が判断？** — 判断者・責任者が明確か
8. **何を対象に？** — 対象範囲が明確か

## 表現ルール（禁則事項）

### 話し言葉→書き言葉の変換

| NG（話し言葉） | OK（書き言葉） |
|---------------|---------------|
| 見ている | 把握している / 参照している |
| 回す | 運用する / 実行する |
| しっかりと | 精緻に |
| はず | 見込みである |
| やる | 実施する / 作業する / 対応する |
| 夏休み | 夏季休暇 |
| バケーション | 休暇 |
| xxはどうか？ | xxはどうか。 |
| ～のイメージ | （言い切る。「資材が行うイメージ」→「資材が行う」） |
| ～ので | ～ため（「件数が多くないので」→「件数が多くないため」） |

### 文体統一
- **「だ・である」調（常体）で統一**
  - NG: 延期です。/ 延期。/ 延期とします。
  - OK: 延期である。/ 延期とする。

### 固有名詞・略語
- 固有名詞は略さず正確に書く
  - NG: 「企画」が... → OK: 「資材企画課」は...
- 組織外の人も見る可能性がある場合は、略語に最初だけ（）で説明をつける
- 一般的でない用語（社内用語、略語など）を用いない

### 時期・タイミング
- 明確に記述する
  - NG: 少し前から、先だって → OK: XX月以降
  - NG: 今後は → OK: XX年度より
  - NG: 昨日、明日 → OK: 昨日（7/8）、明日（7/10）
  - NG: 今週、来週 → OK: 今週（7/6w）、来週（7/13w）
- 週の場合は、月曜日の日付に "w" を付ける

### 出席者のグルーピング
- NG: 出席者：田中、鈴木、山田、高橋
- OK: 出席者：管理：田中、鈴木 / 資材：山田 / 設計：高橋

### 文章テクニック

| ルール | NG | OK | 補足 |
|--------|----|----|------|
| 「～について」で文を始めない | PQ会議について、今後... | PQ会議の定義を今後検討する | 話し言葉の前振りはNG |
| 代名詞を使用しない | そういった面でも... | シェア向上の施策を... | 具体的に何か書く |
| 「具体的には」を活用 | （言いたいことが埋もれる長文） | 結論を先に。具体的には... | 読み手の立場で |
| 長い文章は箇条書き | 4つの可能性を検討... | 箇条書きで列挙 | 1文3行以内が目安 |
| 否定形は避ける | 高くない / 多くない | 低い / 少ない | |
| 「・」と「/」 | 月次・週次の両方 | 月次/週次のいずれ | 「・」はAND、「/」はOR |
| 「～を行う」の多用 | 検討を行う | 検討する | 簡潔に |
| 日本語で書ける英語 | リダンダント / サマる | 冗長 / 要約する | |
| 主語・目的語の省略 | 9月までに調査する | 9月までに企画管理部メンバーが... | |
| 「要検討」の多用 | 事業所別の業務は要検討 | 検討する必要がある | |
| 「させて頂く」 | させて頂く | 行う / 実施する | ACNメンバーの発言には不要 |
| 「頂く」の多用 | 確認頂いた | 確認した | |
| 末尾を「想定」で終わらない | 提示できる想定 | 提示する | 言い切る |
| 「～いく」は使わない | 確認していく | 確認する | |
| 「～に対して」で文を始めない | 進捗に対して… | 進捗は… | 話法であり書き言葉ではNG |
| 「本」「当」の多用禁止 | 本PJ、当PJ | （固有名詞で書く） | |
| 矛盾した擬似熟語を使わない | 基本概念、詳細概要 | 概念、詳細 | |
| 「および」の前に読点 | AおよびB | A、およびB | 並列は「・」で表記 |
| 「鑑みる」の乱用禁止 | 状況を鑑みて | 状況を考慮して | 先例に照らす意味でなければNG |
| 「基本～」を単体で使わない | 基本的に○○する | 基本は○○、例外は△△ | 基本-例外のセットで使う |
| 「お」「ご」の使い分け | ご作業、お検討 | お手伝い、ご確認 | 和語に「お」、漢語に「ご」。過剰に付けない |

### 助詞の正確な使用
- 「は」と「を」を混同しない
  - NG: NPP**は**7月に行う → OK: NPP**を**7月に行う
  - 「NPPは」は他との比較がある場合の話法

## レビュー時の戦略的ポイント

### 自分たちが不利になることは書かない
- 議事録の目的のひとつは証跡を残すこと
- 後々不利になる書き方はしない

### 能動態と受動態の使い分け
- やったことをアピールしたい場合は**能動態**
- 責任回避したい場合は**受動態**

### 「了解した」の記載
- 沈黙肯定で終わった場合でも「了解した」と残す
- 後々の証跡として必要

### 会議後の確認事項
- 「後で確認します」となった事項について、議事録発行までに確認できれば
  「※会議後に、XXXであることを確認」と注記付きで記載する

### 引用元の誤字脱字
- 議事録中では修正し、引用元にも連絡しておく

### 「オフレコ」「ここだけの話」
- 記述しない

### 発言者の言いたかったこと
- 発言者の「言いたかったこと」と実際に「言ったこと」が違う場合は「言いたかったこと」を記述
- 不明瞭な場合は上司と相談

## 改行・体裁ルール

- 名前の途中で改行しない（失礼にあたる）
- 単語・固有名詞の途中で改行しない
- 行末を始め括弧類で改行しない
- 文字位置調整にスペースを使わない（インデント機能を使用）
- 行間設定: Wordの場合は行間1行が見やすい
- 箇条書き記号: 「・」の手打ちではなく箇条書き機能を使用
